# DevToolkit — The Offline-First Developer Toolbox

*21 essential developer utilities. One desktop app. Zero internet required.*

---

## Your Tools. Your Machine. Your Data.

DevToolkit is a free, open-source desktop application that gives developers instant access to **21 everyday utilities** — all running locally on your machine. No browser tabs, no accounts, no data leaving your computer.

Built with Electron, React, and TypeScript, DevToolkit is designed to be the one app you keep pinned to your taskbar.

---

## ✨ Key Features

### 🔒 100% Offline & Private

Every tool runs entirely on your machine. No network requests, no telemetry, no cloud sync. Paste production secrets, decode JWTs with real tokens, and format sensitive payloads with complete confidence. Your data stays yours — always.

### ⚡ Instant & Lightweight

No browser tabs. No page loads. No ads. Launch DevToolkit and your tool is ready in milliseconds. Every tool comes pre-loaded with sample data so you can see how it works the moment you open it.

### 🎨 Dark-First Design

A clean, modern interface built for developers who live in dark mode. Light mode is available too. The UI uses semantic design tokens for a consistent, polished experience across all tools.

### ⭐ Favourites & Quick Search

Pin your most-used tools to the top of the sidebar for one-click access. Use the home screen search bar to find any tool instantly — filtering by name or description as you type.

### 🔓 Free & Open Source

DevToolkit is MIT-licensed. No license keys, no subscriptions, no feature gates. Use it, fork it, extend it, contribute to it.
